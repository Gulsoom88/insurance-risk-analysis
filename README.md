# Insurance Risk & Profitability Analytics Dashboard

## Overview
This project analyzes insurance customer and claims data to identify risk patterns, claim behavior, and profitability trends.

## Objectives
- Analyze customer risk
- Calculate loss ratios
- Identify profitable customer segments
- Build interactive dashboard

## Technologies
- Python
- pandas
- SQL
- SQLite
- Streamlit
- Plotly
